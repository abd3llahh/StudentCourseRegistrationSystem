# Java Registration System

## Description
A console-based Java project that allows students to register for courses.  
This project demonstrates object-oriented programming, collections, input validation, and menu-driven UI.

## Features
- Add courses and students
- Enroll and drop students
- Search for students or courses
- View all students and courses
- Input validation for safe operations

## Tech Stack
- Java
- VS Code

## How to Run
1. Open the project in VS Code.
2. Compile and run `Main.java`.
3. Use the menu to interact with the system.
